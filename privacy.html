개인정보처리방침

악타마 출석봇(이하 "프로그램")은 운영자 개인 컴퓨터에서만 동작하는 출석 기록 프로그램입니다.

수집하는 정보

  • 유튜브 채팅에서 !출석을 입력한 시청자의 유튜브 닉네임과 채널 ID
  • 출석 날짜, 출석 횟수, 연속 출석일, 운영자가 입력한 점수
  • 시청자가 직접 연결한 경우 디스코드 사용자 ID

Google 계정 정보 사용

프로그램은 운영자 본인의 유튜브 계정으로 로그인하여, 방송 채팅에 출석 확인 메시지를 보내는 용도로만 YouTube Data API를 사용합니다. 받은 정보는 운영자 컴퓨터에만 저장되며 다른 곳으로 전송하거나 제3자에게 제공하지 않습니다.

프로그램의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.
